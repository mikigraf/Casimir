# Reporting security issues

Report suspected credential exposure, unsafe subprocess lifetime handling, unsafe checkpoint
restoration or unintended artifact deletion privately through
[GitHub private vulnerability reporting](https://github.com/mikigraf/Casimir/security/advisories/new).
If private reporting is unavailable, open a public issue asking the maintainer for a private
contact channel without including secrets or exploit details.

Do not attach raw transcripts, checkpoints, credentials or proprietary repositories to a public
issue. Include the Casimir version, platform and a minimal redacted reproduction where possible.
This project does not promise a response SLA.
