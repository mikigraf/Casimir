# Pilot acceptance

Three independent pilot users must work on their own repositories using only published
installation and onboarding documentation. Each person records their identity, platform,
Casimir commit/version, repository description (redacted if necessary), and evidence for:

1. Install and verify the native archive or `cargo install`.
2. Run doctor and resolve executable/auth/storage issues.
3. Complete a realistic experiment with executable checks.
4. Explain execution status, check outcome, judge assessment and uncertainty in the report.
5. Interrupt a multi-turn run and recover it without duplicate completed prompts.
6. Preview cleanup, remove owned artifacts, and confirm their source repository remains intact.

Record data-loss, incorrect-result, and onboarding blockers separately; all must be resolved
before 1.0. Do not substitute maintainer or fixture runs for these independent journeys.
No pilot outcomes have been recorded yet.
